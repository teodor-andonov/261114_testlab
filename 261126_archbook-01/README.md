# Archbook 01 — 0.1.0-alpha.1

Initial integrated increment of the 26 November Archbook brief. Browser-only; separate local project sources, shared context, static command/tool/panel registry, native model workers, disposable results, live views and page composition. Synthetic façade only, no confidential geometry.

Run npm install, npm test, npm run dev. Use desktop Chromium. Open Commands (Ctrl+K), then Open demo, or Create project with synthetic fixture in an empty folder. Explicitly rebuild Façade and Canopy, then build Panel analysis with dependencies. Select cells and save a moduleType assignment; rebuild. Save a view/page as readable JSON. Export is explicit.

Capability boundaries: SMLib native USDA, single-shape Replicad STEP, Rhino mesh preview (limited). Exact trimmed 3DM to SMLib, unit/transform conversion, native cross-model geometry handles, exact 3DM export and round-trip tolerances are NOT implemented. Models exchange semantic records, not pretend exact meshes. Agent skill is guidance only; independent runtime packaging and headless render not yet implemented. No real Arena input or adoption validation. Basic relative ES imports, no arbitrary package resolution. Offline caching is best-effort after assets have been loaded. This is not a claim of full brief acceptance. Source execution requires trust; a Worker is not a network sandbox.
